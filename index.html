Aplikasi Pemilihan Mobil Bekas

Sistem Pendukung Keputusan dengan Metode SAW

Sistem pendukung keputusan untuk membantu konsumen memilih mobil bekas di Showroom Sahaja Motor Bekasi. Sebelumnya, pemilihan dilakukan secara manual dan bergantung pada penjelasan lisan serta penilaian subjektif penjual.

Aplikasi menggunakan metode Simple Additive Weighting (SAW) untuk mengolah 8 kriteria (harga, tahun kendaraan, kilometer tempuh, kapasitas mesin, jenis transmisi, jenis bahan bakar, merek, dan tipe kendaraan) menjadi perankingan mobil yang objektif.

Showroom Sahaja Motor BekasiJava (NetBeans)MySQLMetode SAWAplikasi Desktop
Login dengan dua peran: Admin dan User
Kelola data mobil dan data pengguna
Pengaturan kriteria dan bobot
Proses SAW: normalisasi, nilai preferensi, dan hasil ranking
Rekomendasi mobil bagi konsumen
Cetak laporan data mobil, kriteria, nilai preferensi, dan hasil SAW

Aplikasi Penjualan Merchandise

Proyek Kerja Praktik di PT B-Jes Entertainment

Aplikasi desktop untuk mengelola penjualan merchandise PT B-Jes Entertainment. Sebelumnya, data merchandise, customer, dan supplier belum terintegrasi, dan pencatatan transaksi masih berisiko salah input.

Aplikasi ini menyatukan pengelolaan data, transaksi pembelian dan penjualan, pengiriman, serta pembaruan stok otomatis dalam satu sistem, lengkap dengan laporan.

PT B-Jes EntertainmentJava (NetBeans)MySQL (XAMPP)Aplikasi Desktop
Registrasi (sign up) dan login admin
Kelola data barang, customer, dan supplier
Transaksi pembelian/pengadaan dan penjualan merchandise
Pengelolaan pengiriman merchandise
Stok barang diperbarui otomatis setiap transaksi
Laporan penjualan, pengadaan, pengiriman, dan data barang
