# Portofolio Rizki Ashar Siregar

Struktur:

- `index.html`    : halaman utama (dan halaman detail project)
- `css/style.css` : semua styling
- `js/script.js`  : navigasi project dan pratinjau gambar
- `images/`       : foto profil dan gambar project

Hosting di GitHub Pages: upload semua isi folder ini ke repository,
lalu buka Settings > Pages > Branch `main` / folder `/ (root)`.
